System Architecture

Technical Stack

Backend

  • • PHP 8.0+ with PDO for database operations
  • • MySQL/MariaDB database
  • • Session-based authentication
  • • Prepared statements for security
  • • bcrypt password hashing

Frontend

  • • Modern HTML5 & CSS3
  • • Vanilla JavaScript
  • • Responsive design with Tailwind CSS
  • • Material Design icons
  • • Glass morphism UI components

Database Schema

Core Tables

Users Table

Stores user authentication and profile information with role-based access. 

users (id, name, email, password, role, building_id, created_at, last_login)

Buildings Table

Contains society building information and unit details. 

buildings (id, name, address, total_units, created_at)

Maintenance Table

Tracks maintenance requests and their status. 

maintenance (id, user_id, building_id, description, status, created_at)

API Endpoints

Authentication

POST /backend/auth/login.php

User login with email and password

POST /backend/auth/logout.php

User logout and session destruction

Installation Steps

Setup Database

2

Configure Database

Update database credentials in backend/config/database.php.

3

Start Web Server

Use PHP built-in server or Apache/Nginx to serve the application.

4

Login

Access the application and login with test credentials.
